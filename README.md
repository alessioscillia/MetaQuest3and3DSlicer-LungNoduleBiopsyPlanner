# Bringing Augmented Reality Surgical Guidance to Meta Quest 3
A tool to support CT-guided lung biopsy procedures using AR, via the Meta Quest 3 headset. This application allows the patient’s thoracic model—generated from CT segmentation—to be superimposed onto the patient using an automatic registration method via QR code. In addition, it enables both automatic and manual selection of the optimal trajectory the needle should follow to target the nodule, as well as a needle tracking system that allows for the evaluation of the deviation between the actual trajectory and the virtually selected one.
